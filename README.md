# 🏠 Flat Hunter — Belgrade

Расширение для Google Chrome (Manifest V3), чтобы собирать, тегировать и отслеживать квартиры для долгосрочной аренды с HaloOglasi, CityExpert и других сайтов.

Написано на чистом JavaScript, HTML и CSS, без сборщиков и фреймворков.

## Возможности

- **Парсинг объявления в один клик**: заголовок, цена, URL, район и тип отопления.
- **Все районы Белграда**, сгруппированные по общинам: Сеньяк, Дединье, Врачар, Дорчол, Белград на воде, блоки Нового Белграда и т.д. Парсер понимает латиницу, кириллицу и падежи («na Senjaku», «u Zemunu», «Blok 45»).
- **10 типов отопления**: CG, EG, газ, тепловой насос, тёплый пол, ТА-печь, норвежские радиаторы, инвертор, электричество, твёрдое топливо.
- **Статусы**: Интересно → Не дозвонился → Договорился на просмотр → Посмотрел - Думаю → Готов снимать / Отказ.
- **База квартир**: канбан с перетаскиванием карточек между статусами, таблица, фильтры по району и общине, pet-friendly, белый картон, поиск.
- **Экспорт в CSV** для Excel и Google Sheets.
- **Обновление в один клик**: двойной клик по `update-mac.command` или `update-windows.bat`, и при следующем открытии расширение переходит на новую версию.

## Установка

1. Склонируйте репозиторий (через `git clone` или GitHub Desktop) в удобную папку, например `~/Projects/flat-hunter`.
2. Откройте `chrome://extensions` и включите **Режим разработчика** справа вверху.
3. Нажмите **Загрузить распакованное** и выберите папку репозитория.
4. Закрепите иконку на панели (значок 🧩 → 📌).

> ⚠️ Загружайте расширение именно из папки с git-репозиторием, а не из скачанного ZIP. Иначе обновление не будет работать.

## Обновление

Обновление запускается только вручную, когда вы сами захотите. Фоновых задач и таймеров нет.

1. **Запустите «ручку»** двойным кликом в папке репозитория:
   - macOS: `update-mac.command`
   - Windows: `update-windows.bat`

   Скрипт скачает свежую версию с GitHub (`git pull`). То же самое делает кнопка «Pull origin» в GitHub Desktop.
2. **Откройте расширение.**
   - «Моя база» перезагрузит расширение сама и откроется уже в новой версии.
   - В popup появится плашка «🔄 Доступна новая версия» с кнопкой «Обновить».

Сохранённые квартиры при обновлении не пропадают. Текущая версия показана в базе под заголовком.

> macOS при первом запуске `.command` может спросить разрешение. Если файл не открывается двойным кликом, выполните в Терминале `chmod +x update-mac.command`.

## Как пользоваться

1. Откройте объявление и нажмите на иконку расширения.
2. Нажмите **✨ Спарсить данные с текущей страницы**. Поля, которые не удалось найти, подсветятся оранжевым.
3. Выберите статус, отметьте белый картон и pet-friendly, запишите в комментарий депозит, Инфостан и контакты.
4. Нажмите **Сохранить квартиру**. Если открыть то же объявление ещё раз, форма откроется в режиме редактирования.
5. **Открыть мою базу →** ведёт на канбан и таблицу. Карточки можно перетаскивать между статусами.

## Структура

| Файл | Назначение |
|---|---|
| `manifest.json` | Манифест MV3 |
| `background.js` | Service worker: бейдж с числом квартир, применение обновлений |
| `data.js` | Справочники: статусы, районы, отопление; распознавание района и отопления |
| `content.js` | Парсер страницы объявления (инжектится по клику) |
| `popup.html` / `popup.js` | Окно расширения с формой |
| `dashboard.html` / `dashboard.js` | База квартир: канбан, таблица, фильтры, экспорт |
| `styles.css` | Общие стили в духе Notion |
| `update-mac.command` / `update-windows.bat` | «Ручка» обновления: `git pull` по двойному клику |

### Добавить район или тип отопления

Отредактируйте `DISTRICT_GROUPS` или `HEATING_TYPES` в `data.js`. Распознавание кириллицы и падежей подключится автоматически.

### Если парсер не находит данные на новом сайте

Добавьте правило в `SITE_RULES` в `content.js`: селекторы заголовка, цены и блока адреса.

## Данные

Все квартиры хранятся локально в `chrome.storage.local` этого браузера. Делайте экспорт в CSV как резервную копию.
